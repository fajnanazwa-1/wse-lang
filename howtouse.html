How to use?

To create an object on the page, you must use one of these object types:

  • label
  • button
  • input

If you want to create text, use the label type.

First, let's create a basic JSON object:

{
}

Now, name your object on page:

{
    "hello world text": {
        // here we add informations about this text
    }
}

Now, we must to say to program what type is the "hello world text" object.
We can do it using "type" information:

{
    "hello world text": {
        "type": "label"
    }
}

Next, to define object`s text use "text" information:

{
    "hello world text": {
        "type": "label",
        "text": "Hello, World!"
    }
}

You can add the "css" information for define object`s css:

{
    "hello world text": {
        "type": "label",
        "text": "Hello, World!",
        "css": "background-color: red;"
    }
}

Congratulations. We have working page!!
